# AI-Powered-Epilepsy-Seizure-Detection-System
Built a Machine Learning-based web application for detecting epileptic seizures using EEG signal data. Compared multiple ML models including SVM, KNN, Logistic Regression, and ANN. Achieved ~94% accuracy and deployed the project using Streamlit for real-time EEG analysis and prediction.
